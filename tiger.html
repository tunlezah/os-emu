Tiger bet that the filing cabinet was finished

Spotlight was not a faster search box. It was a proposition: that the hierarchical filesystem — folders inside folders, decided in advance, maintained by hand — had run its course, and that a metadata index would replace it.

Everything downstream followed from that bet. Smart Folders were saved queries that behaved like directories. Smart Mailboxes did the same to email. Get Info grew metadata fields, including a Spotlight Comment you write by hand and the index then consumes. The command line got mdfind. The claim was that you would stop filing things and start asking for them.

The exhibit is built in that order. The metadata index and its query engine were written first; the Spotlight menu, the Finder’s search, Smart Folders, Smart Mailboxes, Get Info and mdfind are all clients of that one index, and none of them owns a search implementation of its own. Build a search box first and you get a facade that cannot do any of the rest.

Try the closed loop

  1. Open Terminal and run touch ~/Documents/harbour-notes.txt.
  2. Press ⌘Space and type harbour. It is already there.
  3. Run mdls ~/Documents/harbour-notes.txt and compare it with the same file’s Get Info window. Same attributes, same index.

Then watch the bet made tangible

  1. In the Finder, click the search field, type something, and press Save to make a Smart Folder — a purple gear-badged folder in the Sidebar whose contents are the live result of a query.
  2. Now save a matching file somewhere else entirely — the Desktop, a folder you invented, anywhere — from TextEdit or from the Terminal.
  3. Open the Smart Folder. The file is in it. Nobody put it there.

The bet was half-right, and that is why it is a museum piece

Search won completely — nobody hunts through folders anymore. But hierarchy never died, people kept filing, and the broader idea that the filesystem should be a database quietly evaporated. Smart Folders remained a power-user feature that most Mac users never made one of.

Microsoft was asking the same question at the same time. WinFS — a relational metadata store meant to sit over NTFS — was promised for Longhorn, cut from it in 2004, and formally cancelled in June 2006: one year after Spotlight shipped. Tiger is the last mainstream operating system that seriously tried to make metadata the organising principle of a computer.

Three attempts at the same idea, from three directions. If this museum’s BeOS R5 and 超漢字 exhibits are open in other tabs, put them beside this one. BeOS had BFS attributes and live queries in 2000 and shipped a mail client that was a database query. Tiger had Spotlight and Smart Folders in 2005. Chokanji has a filesystem that is a hypertext web rather than a tree. None of the three won. All three were right about something.

Who was right? A visitor who has not deliberately filed anything in a decade, and who also still maintains a folder tree out of habit, is in the best possible position to judge.

Things worth finding

  • Drop a Dashboard widget and watch the ripple. Then do it again, which is what everybody did in 2005.
  • Type something into the Spotlight Comments field of a Get Info window, then search for it. A hand-authored attribute the index consumes — the whole idea in one field.
  • Search System Preferences from Spotlight and watch the pane get a spotlight beam.

The architecture transition happened underneath this release, and nobody noticed

Tiger shipped on PowerPC in April 2005. In January 2006 the first Intel Macs arrived running 10.4.4, and Rosetta translated PowerPC binaries on the fly so transparently that most users never learned it existed. An entire computing platform changed instruction set beneath its own software, and the headline user experience was “some apps feel a bit slower.” That is an extraordinary piece of engineering to have been that boring.

Switch the machine underneath this exhibit

PowerPC G5Intel Core Duo

Switching changes what uname -a, sw_vers, system_profiler and About This Mac report, which applications run natively, and whether Classic is available at all.

  • Cartography Studio 2.1 is PowerPC-only. Get Info says so. On Intel it launches under Rosetta and is visibly, honestly slower; Activity Monitor gives it a Kind column that reads PowerPC.
  • Lumen Notes 1.4 is a Universal Binary and runs natively on either processor.
  • Classic — the Mac OS 9 compatibility environment — was PowerPC-only. Switch to Intel and it is gone, exactly as it went for real users. For anyone still running pre-OS-X software in 2006, that was the end of the road, and it arrived without ceremony.
  • Anything with kernel extensions or hand-written PowerPC assembly did not survive the crossing at all. Rosetta translated user-space PowerPC code; it did not translate drivers, and it never ran a G5-only instruction.

And Tiger is where Mac OS X stopped apologising

10.0 was a beautiful, slow, incomplete promise. By 10.4 it was fast, complete, stable, and shipping a genuinely novel idea rather than catching up to one.

Dashboard widgets were HTML, CSS and JavaScript

This is the most delightful implementation fact in the whole museum. Apple built the widget layer on WebKit; a widget was a bundle — a directory ending in .wdgt — containing a web page, its stylesheet, its script, and an Info.plist declaring its name, its size and its defaults.

So recreating Dashboard in a browser is not a simulation of the technology. It is the technology, in its native medium, twenty years later.

This exhibit takes that seriously. Every widget here is one self-contained unit — its own markup, its own stylesheet, its own script and a manifest declaring name, size and default preferences — registered with defineWidget(). The host that lays them out, flips them over, saves their preferences and drops them with a ripple knows nothing about any individual widget. The structural test: adding a new widget means adding one self-contained unit and changing nothing else. That is exactly how Apple’s bundles worked, and it is the one place where this museum’s single-file constraint and its subject’s real architecture agree completely.

The Konfabulator question

Dashboard closely resembled Konfabulator, an independent product by Arlo Rose and Perry Clarke released in 2003, which put scriptable floating widgets on the Mac desktop and had a substantial following. The resemblance was widely and heatedly discussed when Dashboard was announced at WWDC in June 2004; Apple’s layer differed in being a summoned overlay built on WebKit rather than persistent desktop objects with their own scripting runtime. Konfabulator was acquired by Yahoo in July 2005 and released free, becoming Yahoo Widgets; it was discontinued in 2012. Dashboard itself was disabled by default in 2014 and removed in 2019. Those are the facts and that was the controversy. This exhibit does not adjudicate it.

launchd replaced half the Unix startup world

Tiger shipped launchd, and it is a genuinely significant change that arrived with far less noise than Spotlight. One supervisor took over the jobs of init, inetd, xinetd, cron, at, watchdogd and Apple’s own SystemStarter: it starts daemons, restarts them when they die, holds their listening sockets so they can be launched on demand, and runs their periodic work — all from one property list per job.

Try launchctl list in the Terminal, then look at /System/Library/LaunchDaemons. The idea propagated well beyond Apple: systemd, Upstart and SMF all argued with it, borrowed from it, or both.

The rest of the layer

  • bash is the default shell. Tiger is firmly pre-zsh; zsh became the default fourteen years later.
  • Darwin 8, a BSD userland, and a real /usr/bin full of it.
  • mdfind, mdls, mdimport and mdutil speak to the same index the Spotlight menu does. This is the closed loop and it is the point.
  • defaults write genuinely alters this simulation’s settings — try defaults write com.apple.dock orientation left.
  • sw_vers, uname -a, ps aux, top, lipo -info, sysctl, system_profiler.

VoiceOver

Tiger shipped VoiceOver: a screen reader built into the operating system, at no extra cost, controlled from Universal Access, with keyboard navigation of the whole interface and speech for the things it landed on. Before it, blind Mac users bought third-party software — outSPOKEN, or later a Windows machine and JAWS — and lived with whatever the vendor supported. This was the first serious screen reader built into a mainstream desktop operating system rather than bolted onto one, and it changed what shipping an accessible OS was assumed to mean.

Open System Preferences → Universal Access → Seeing and turn VoiceOver on. Where your browser provides the Web Speech API this exhibit will genuinely speak the interface elements you move over, using your system voices. Where it does not, it captions them instead.

It was not finished in 2005 — web browsing in particular was thin, and it improved a great deal over the following releases. Shipping it at all was the significant part.

What this release got wrong, kept

The first indexing pass was brutal

Spotlight on a fresh Tiger install pinned the disk and the CPU for hours while mdimport walked the volume, and early adopters complained loudly. The progress estimate was famously unreliable. This exhibit reproduces the first-boot indexing state, estimate and all — the estimate lies, as it did. You can skip it; in 2005 you could not.

Brushed metal was applied inconsistently

Metal spread further in 10.4 than in any release before or since: Finder, Safari, iTunes, iChat, Mail, Preview, Calculator, Address Book, DVD Player. Meanwhile Apple’s own Human Interface Guidelines said metal was for windows representing a physical device or a single-window application, and Apple broke that rule repeatedly — the Finder is neither. Third-party developers complained for years that the look was effectively unobtainable: the real texture was not a public API, so approximations of it were everywhere and none of them matched. Tiger also shipped the newer unified title-bar-and-toolbar style alongside metal rather than instead of it, which made the inconsistency worse, not better.

Mail 2’s toolbar

The redesigned Mail replaced ordinary toolbar buttons with wide metal capsules containing small glyphs. People disliked them enough that Apple reverted the design in Leopard. They are reproduced here as shipped. The exhibit is not improved by fixing what people complained about.

Rosetta was transparent but slow

Roughly half the speed of native code for ordinary work, worse for anything floating-point-heavy, and it never covered kernel extensions, PowerPC assembly, Classic, or software that assumed a G4/G5 vector unit. Photoshop under Rosetta was a famous grievance.

The metadata bet did not fully land

People kept filing. Smart Folders remained a power-user feature. The thing Spotlight actually killed was browsing to find, not folders.

Dashboard was forgotten

Widgets proliferated, most were used twice, and the layer was disabled by default in OS X Yosemite and removed in macOS Catalina.

Fenced hard in both directions

Tiger sits between two very different neighbours, and an exhibit is only worth anything if it refuses both.

The vocabulary is period-correct too: Mac OS X, with the “Mac” still on the front — it was not dropped until Mountain Lion in 2012, and “macOS” is seven years away.

What this is not

Nothing real runs. No PowerPC is emulated, no Mach-O binary is parsed, no software is executed. Every icon, texture and wallpaper here was drawn in code for this exhibit; none of Apple’s artwork, marks or the tiger-striped X appears anywhere, and the place where the logo would sit holds a neutral museum placeholder. It is a front-end re-creation of a look, a feel and one large idea.
