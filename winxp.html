Windows XP Service Pack 2 — 25 August 2004

The release where the default flipped from open to closed.

Service Pack 2 is the moment the industry admitted the network was hostile

Windows XP is the most widely used operating system in the history of computing, and it refused to die. Extended support did not end until April 2014 — thirteen years after release — and it outlived even that in cash machines, hospital equipment and factory floors.

But longevity is not why this exhibit is Service Pack 2 rather than the original release.

XP shipped in October 2001 configured the way software had always been configured: open. The firewall was off. Services listened on the network by default. Internet Explorer executed active content with enthusiasm. Then came Code Red and Nimda, then Blaster in August 2003 and Sasser in April 2004 — worms that reached unpatched machines in minutes, purely by being connected to the internet. The era’s grim folk statistic was that a freshly installed, unpatched XP machine plugged into a modem could be compromised before Windows Update had finished downloading the patch that would have prevented it.

SP2 was two years in the making and it was less a service pack than a different operating system wearing the same clothes. The firewall was on by default. A Security Center appeared to nag about the firewall, updates and antivirus. Data Execution Prevention arrived. Internet Explorer gained a pop-up blocker and the yellow Information Bar. Attachments began arriving with warnings about unverified publishers. It delayed Longhorn by roughly a year, and it changed how the whole industry shipped software.

Before SP2

Systems shipped open. You closed what you did not want — if you knew it was there, if you knew how, and if you did it before something else found it.

After SP2

Systems shipped closed. You open what you need, one prompt at a time, and the system keeps a list.

Every operating system on Earth now works the second way. This is the release where the default flipped, under duress, in 2004 — and the endless permission prompts on the phone in your pocket are its direct descendants.

The argument takes fifteen seconds. Open Security Center, turn the firewall off, then use Connect To → Dial-up to the Internet. Watch what 2003 looked like. Turn the firewall back on and connect again: nothing happens at all. That difference is the whole of Service Pack 2.

How to use it

This is a front-end simulation. No CPU is emulated, no real code executes, nothing talks to a network. It is a museum exhibit you can click on, in one HTML file, and it works from file:// with no server.

Getting in

  • The machine boots on load. Press F8 during POST for the Windows Advanced Options Menu — the one with the SP2 addition in it.
  • On the Welcome screen, click a user tile. Owner is the administrator; Kim is a limited account with unread mail.
  • Press Ctrl+Alt+Delete twice on the Welcome screen for the classic logon dialog that domain machines used.

Once you are in

  • start → the two-column menu. The most-frequently-used list on the left fills itself in as you open things; it is empty on a fresh install because it has nothing to go on yet.
  • Right-click the desktop for Properties (themes, wallpaper), the taskbar for Properties (Classic Start menu, hiding inactive icons), and files for their menus.
  • Control Panel opens in Category View, which was new in XP. The Switch to Classic View link is in the sidebar, where a lot of people went first.
  • Command Prompt understands forty-odd commands over a real (simulated) filesystem, with wildcards, long names and spaces in paths. Try ver, then systeminfo, and check that they agree.
  • Everything you change is kept in localStorage. There is a full reset at the bottom of this guide.

Best on a desktop browser with a keyboard. The interface predates touch by years, and right-click is load-bearing.

The boot sequence, stage by stage

The boot is the first thing you see and the first thing anyone who used the machine will check, so it is built here in order and to the right timings.

  1. BIOS POST. Memory count, IDE detection, a boot device summary. Brief.
  2. NTLDR. With one entry in boot.ini the text-mode boot menu is skipped, which is why most people never saw it. Add a second entry from System Properties → Advanced → Startup and Recovery and it appears, with its countdown.
  3. F8 — Windows Advanced Options Menu. Text mode on black. Note the entry reading Disable automatic restart on system failure: SP2 added that line, because XP’s default was to reboot instantly on a stop error and nobody could read their own blue screen. It is period-correct and it is also a joke at the operating system’s expense.
  4. The splash. Black, centred, and the part most recreations get wrong: the progress indicator is not a filling bar. It is a recessed trough with three blue blocks that march left to right, leave at the right end and reappear at the left, forever, at constant speed. It conveys no progress information whatsoever. No sound plays here.
  5. A brief black screen, then blue.
  6. The Welcome screen. New in XP and a genuine break with the NT-style Ctrl+Alt+Del dialog: a blue field split by a vertical separator that glows brightest at its centre, “Welcome” on the left, user tiles on the right, Turn off computer at the bottom left.
  7. Logging on. The tiles slide away, “Welcome” centres itself, and the desktop draws in — taskbar first, then icons. The startup sound plays as the desktop appears, not during the splash. This trips up almost every recreation.
  8. First boot only. The balloon tips arrive in sequence: the tour prompt, the unused desktop icons offer, and — this being SP2 — a Security Center notification.

Safe Mode actually works

Pick it from the F8 menu. You get 640×480, sixteen colours, Safe Mode in all four corners and the version string across the top. Most of the shell is there and most of the drivers are not, which is the point of it.

Shutdown mirrors it

The Turn Off Computer dialog with its three glossy buttons over a dimmed, desaturated desktop, then “Windows is shutting down…” on blue, then the power-off screen. Listen for the shutdown sound: it plays while you can still press Cancel.

Security Center and the SP2 machinery

This is the thesis in software, so it is built as one policy model with many faces rather than a set of decorative dialogs. Change the firewall in Security Center and the notification area shield, the balloon nags, the Internet Explorer zones, the attachment warnings and the scenario engine all see the same change, because they are all reading the same object.

The Information Bar is worth watching for its own sake. It appears so often that it becomes background noise, which is precisely what happened: a security control that fires constantly trains people to dismiss it. That lesson is still being relearned.

August 2003, recreated as an artifact

With the firewall switched off, connecting this machine to the simulated network produces the era’s most memorable dialog: a system shutdown countdown, attributed to a system account, with sixty seconds on the clock and an instruction to save your work.

Millions of people saw that dialog in August 2003 and had no idea what it meant. It arrived on home machines, on office machines, on a train station’s departure boards and on hospital screens, and it arrived again after every restart. It is the single most widely witnessed error dialog of its decade.

Then switch the firewall on and connect again. Nothing happens at all. That is the entire argument of Service Pack 2, delivered in about fifteen seconds.

This recreation is strictly cosmetic and deliberately incurious. It reproduces a dialog and a timeline as historical artifacts. It contains no technical detail about how any of it worked — nothing about protocols, nothing about vulnerabilities, nothing that would function as instruction. The exhibit is about the dialog people remember and the policy change it forced, not the mechanism. That is not squeamishness; the mechanism is simply not the interesting part of this story.

What is interesting is the response. Microsoft’s answer was not a patch — there had been a patch, weeks earlier, and it had not helped enough. The answer was to change the default posture of the operating system, ship it to a quarter of a billion machines, and accept that a great deal of third-party software would break.

Luna, and the people who turned it off within minutes

Luna was a sharp break from Windows 2000’s grey: rounded, glossy, saturated, soft shadows, a green Start button and blue everything. It was widely derided at launch as “Fisher-Price”, and a substantial fraction of users switched to Windows Classic immediately and stayed there for a decade.

So Classic here is not a colour swap. Pick it in Display Properties → Themes and the corners square off, the gloss disappears, the title bars go navy-to-pale-blue, the Start menu becomes one grey column, the scrollbars turn grey and the taskbar loses its gradient. It is Windows 2000, and it is one click away, exactly as it was.

Luna also shipped in three colour schemes — Blue, Olive Green and Silver. Olive was reportedly built for the machines that came with beige plastic. Almost nobody used it.

Windows Product Activation

XP was the first mainstream consumer Windows to require activation. A fresh install gave you thirty days, counted down in a balloon, after which the machine would let you log on and then let you do nothing except activate. It was deeply resented: it treated legitimate purchasers as suspects, it tied a licence to a hardware fingerprint, and it turned a motherboard failure into a phone call.

The activation wizard is here with its grace-period countdown, its two routes — internet or telephone — and its installation ID. Activating it does nothing except stop the balloon, which is also what happened.

Honest limitations

  • XP RTM’s security posture is the reason SP2 existed. Stated plainly, because the exhibit’s thesis depends on not softening it: the machine shipped in a configuration that could not survive contact with the 2003 internet.
  • Luna was mocked at launch, and a large number of people switched to Windows Classic within minutes of first boot.
  • Product activation was unpopular and treated legitimate users as suspects.
  • Search Companion, the animated dog and the Common Tasks pane were all divisive, and all three were removed by later releases. About half the people who met the dog turned it off immediately; the setting to do that is in Search Companion’s preferences, where it always was.
  • SP2 broke a considerable amount of third-party software by turning the firewall on, and enterprise deployment was painful enough that Microsoft shipped a mechanism to block the update while administrators caught up.
  • The darker side of longevity: XP’s refusal to die left a very large installed base of unsupported machines after April 2014 — a security story of its own, and one still running in places.
  • This is a simulation, not an emulation. No original binaries, no real drivers, no network. The filesystem, the registry, the process list and the games are all written from scratch to behave like the originals; where the real thing had depth this has a convincing surface, and where it counts — the security policy model, the shell, the command interpreter, pinball — it has some actual machinery.
  • The artwork is original. Bliss is a photograph by Charles O’Rear and is still under copyright, so the hill here is an original composition drawn in code, an homage and not a copy. The XP icons were drawn by The Iconfactory; these are original drawings in that style, and wherever the Windows flag would sit there is a neutral four-pane placeholder.

What is and isn’t here

The exhibit is fenced in both directions, because a period recreation that leaks is worse than no recreation at all.

Nothing from later

No Aero glass. No Vista or 7 taskbar and no superbar. No UAC prompts. No ribbon in Explorer. No Start screen. No tabs in Internet Explorer. No search box in the Start menu.

Nothing from earlier

This is not Windows 2000 in a blue skin. Luna, the two-column Start menu, Common Tasks, the Welcome screen and Fast User Switching are all new here — and Classic is offered as a genuine full alternative rather than a theme.

And nothing from XP RTM that SP2 changed. The firewall is on. Security Center exists. The pop-up blocker is present. The Information Bar appears. The Attachment Execution Service marks downloads. The F8 menu carries the line about not restarting automatically. Those are the differences that make this SP2 rather than XP, and they are the exhibit.

The vocabulary is period too: My Computer, My Documents, Control Panel, Windows Explorer, Recycle Bin, Quick Launch, and the notification area — which everybody called the system tray, but which the interface never called that about itself.

Easter eggs and things to try

  • The F8 menu’s SP2 addition, and the blue screen it finally lets you read. Trigger a stop error from Help and Support → troubleshooting or by pressing Ctrl+Shift+B. By default the machine reboots before you can read a word. Boot with Disable automatic restart on system failure and it waits.
  • 3D Pinball for Windows — Space Cadet, genuinely playable, with a high score table that persists. Cut after XP, and a generation has never stopped mentioning it. Space launches, Z and / are the flippers.
  • The dog. Search Companion’s animated character, drawn fresh for this exhibit, with the preference that removes it exactly where it used to live.
  • The Information Bar, appearing so often it becomes furniture.
  • ver and systeminfo agreeing on the build number, because they read the same value.
  • The Windows Classic theme, one click away, restoring Windows 2000 entirely.
  • A desktop shortcut left by a previous user pointing at something that is no longer there. Double-click it.
  • The startup and shutdown sounds — synthesised here, in the era’s spirit — and the fact that the shutdown sound plays while Cancel is still available.
  • A Security Center that will not stop nagging until every panel is green.
  • Fast User Switching: switch to Kim, open something, switch back. Both sessions keep their programs, and Task Manager’s Users tab knows.

Everything you change lives in this browser’s localStorage. Erase it all and start from a fresh install — which will also bring back the first-boot balloons.
